# Документация E+E Master

- `architecture/` — описание текущей архитектуры платформы;
- `adr/` — Architecture Decision Records;
- `development/` — локальная разработка и проверка;
- `requirements/` — принципы и требования проекта;
- `research/` — доказательства, эксперименты и выводы фазы исследования;
- `product/` — будущая продуктовая документация.

Значимые архитектурные утверждения должны ссылаться на первичный источник и
содержать дату проверки. Решения, влияющие на архитектуру, фиксируются ADR до
реализации.
