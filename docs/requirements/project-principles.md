# Принципы и исходные требования

## Проект

- Название: E+E Master.
- Репозиторий: `g1357/epe-master`.
- Будущий публичный домен: `epe-m.ru`.
- Будущий hosting: Beget.

## Архитектурные принципы

1. Основой является Varbase 11 на Drupal 11.
2. Первая фаза посвящена глубокому исследованию платформы.
3. Штатные возможности платформы имеют приоритет над custom-кодом.
4. Требование сначала сопоставляется с естественной моделью платформы.
5. Custom допустим только после доказанного ограничения платформы и ADR.
6. PHP-зависимости управляются только Composer.
7. Локальная среда управляется DDEV.
8. Git и GitHub используются с первого этапа.
9. Основная документация хранится в репозитории.

## Языки

- Русский и английский поддерживаются с начала проекта.
- Материал может существовать только на одном языке.
- Перевод не обязателен для публикации исходного материала.
- Точная языковая модель и fallback-поведение должны быть проверены в
  capability research до настройки контентных типов.

## Ограничения текущей фазы

Не реализуются бизнес-функции, собственные модули, собственная тема,
production deployment и интеграции.
