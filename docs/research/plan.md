# Phase 1 research plan

## Goal

Decide whether Varbase 11 is a suitable foundation for E+E Master and identify
the smallest maintainable Varbase baseline.

## Workstreams

| Workstream | Evidence to produce |
| --- | --- |
| Upstream maturity | Release status, support policy, roadmap, known blockers |
| Reproducibility | Locked Composer install and documented DDEV bootstrap |
| Architecture | Package, recipe, patch, config, and extension inventory |
| Editorial UX | Findings from representative author/editor/admin journeys |
| Front end | Theme inheritance, UI Patterns, Canvas/Layout Builder comparison |
| Operations | Update, rollback, backup, cache, cron, queue, and observability notes |
| Quality | Static analysis, test strategy, accessibility and performance baselines |
| Security | Roles, permissions, dependencies, headers, secrets, and supply chain |

## Deliverables

1. Capability matrix with fit/gap/unknown status.
2. Reproducible research environment.
3. Architecture decision: adopt, adopt with constraints, or reject.
4. Initial implementation backlog, only after the decision.

## Out of scope

- Product features.
- Custom modules or themes.
- Production infrastructure.
- Content migration.
- Third-party integrations.
